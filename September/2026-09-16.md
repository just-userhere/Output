## 1. Kubernetes v1.37: Pod-Level Resource Managers graduated to Beta

**Category:** DevOps

### What happened

With the release of Kubernetes v1.37, the Pod-Level Resource Managers feature has graduated to Beta status (disabled by default)! First introduced as an Alpha feature in Kubernetes v1.36 , this enhancement builds on Pod-Level Resources by equipping Kubelet's Topology Manager, CPU Manager, and Memory Manager to use Pod-level resource declarations ( .spec.resources ) directly when making hardware placement decisions.

Affects delivery pipelines and operations — useful for platform engineers standardizing builds and deploys. In this case: With the release of Kubernetes v1.37, the Pod-Level Resource Managers feature has graduated to Beta status (disabled by default)!

## 3. Kubernetes v1.37: Memory QoS Graduates to Beta

**Category:** DevOps

### What happened

Memory QoS has graduated to Beta in Kubernetes v1.37 and is now enabled by default. On Linux nodes running cgroup v2, the feature uses the memory controller to give the kernel better guidance on how to treat container memory.

### Why it matters

Affects delivery pipelines and operations — useful for platform engineers standardizing builds and deploys. In this case: Memory QoS has graduated to Beta in Kubernetes v1.37 and is now enabled by default.

**Source:** [Kubernetes Blog](https://kubernetes.io/blog/2026/09/14/kubernetes-v1-37-memory-qos-graduates-to-beta/) — 2026-09-14
